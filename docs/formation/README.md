# Formation Flutter — Gestion d’état et stockage local avec Drift

Cours progressif en français, réparti en **25 fichiers de modules indépendants**. Chaque module contient son objectif, l’explication, les extraits, le déroulement interne, les questions, l’exercice et le lien vers la suite. Le mini-projet, les exercices finaux et les corrigés sont également séparés.

Les exemples utilisent principalement le fil rouge **projets et tâches**. Les principes Flutter/Dart/SQL sont durables. Les exemples Drift suivent la documentation officielle consultée le **10 octobre 2026** (guide indiquant Drift 2.35.x au moment de la vérification). Les versions précises et certains détails d’API évoluent : vérifiez les références et la version réellement résolue par votre projet.

## Méthode d’étude

1. Étudiez un seul fichier de module à la fois.
2. Répondez aux questions et réalisez l’exercice avant de lire les corrigés.
3. Utilisez les liens de navigation au début de chaque module pour avancer ou revenir au sommaire.
4. Terminez par les exercices finaux, puis consultez les réponses regroupées.
